# car_state_machine

Скетч [main.ino](main.ino) управляет машинкой с двумя ультразвуковыми датчиками:

- **передний датчик** — обнаружение препятствия,
- **левый датчик** — удержание дистанции до стены слева.

Логика похожа на простую state machine: в каждый момент выполняется один из сценариев — объезд препятствия или движение с коррекцией по левой стене.

---

## Пины и моторы

### Моторы

- `DIR_RIGHT = 4`
- `SPEED_RIGHT = 5` (PWM)
- `DIR_LEFT = 7`
- `SPEED_LEFT = 6` (PWM)

Направления заданы константами:

- `LEFT_FORWARD = LOW`, `LEFT_BACKWARD = HIGH`
- `RIGHT_FORWARD = LOW`, `RIGHT_BACKWARD = HIGH`

Функции управления:

- `move(left_dir, left_speed, right_dir, right_speed)` — базовая функция,
- `forward(speed)` / `backward(speed)`,
- `turn_left(steepness)` / `turn_right(steepness)`,
- `rotate_left(speed)` / `rotate_right(speed)`.

---

## Ультразвуковые датчики

- Передний: `TRIG_FRONT = 8`, `ECHO_FRONT = 9`
- Левый: `TRIG_LEFT = 10`, `ECHO_LEFT = 11`

Функция `getDistance()`:

1. отправляет триггер-импульс 10 мкс,
2. измеряет время эха через `pulseIn(..., 30000)`,
3. переводит в сантиметры (`duration / 58`),
4. если эхо не пришло, возвращает `999` (условно «очень далеко/нет данных»).

---

## Параметры поведения

- `STOP_DISTANCE_FRONT = 20` см — если спереди ближе, чем 20 см, нужен объезд.
- `TARGET_DIST_LEFT = 15` см — целевая дистанция до левой стены.
- `TOLERANCE = 3` см — зона допуска.
- `MAX_WALL_DIST = 40` см — если слева дальше, считаем, что стены рядом нет.

Скорости:

- `BASE_SPEED = 150`
- `CORRECT_SPEED = 50`
- `TURN_SPEED = 150`

---

## Основная логика `loop()`

Каждый цикл:

1. читается расстояние спереди (`distFront`) и слева (`distLeft`),
2. выбирается один из двух режимов:

### 1) Режим «препятствие спереди»

Если `distFront < STOP_DISTANCE_FRONT`:

- остановка,
- `rotate_right(TURN_SPEED)` (поворот на месте вправо),
- ожидание, пока спереди не появится достаточный проход:
  - `checkFront > STOP_DISTANCE_FRONT + 15` **или** `checkFront == 999`,
- короткая пауза и снова стоп.

То есть машинка крутится вправо, пока не «увидит» свободное направление.

### 2) Режим «движение вдоль стены слева»

Если препятствия спереди нет:

- если слева есть стена (`distLeft < MAX_WALL_DIST`), включается коррекция:
  - слишком близко к стене (`distLeft < TARGET_DIST_LEFT - TOLERANCE`) → смещение вправо,
  - слишком далеко (`distLeft > TARGET_DIST_LEFT + TOLERANCE`) → смещение влево,
  - в пределах допуска → движение прямо.
- если слева стены нет — просто `forward(BASE_SPEED)`.

В конце цикла `delay(30)`.

---

## Что важно понимать

- Это **реактивный** алгоритм без карты и одометрии.
- Значения `STOP_DISTANCE_FRONT`, `TARGET_DIST_LEFT`, `BASE_SPEED`, `CORRECT_SPEED` подбираются экспериментально под конкретную платформу.
- Возврат `999` из `getDistance()` используется как «нет уверенного эха», что в логике обхода трактуется как возможный свободный путь.

---

## Быстрый сценарий запуска

1. Проверить подключение моторов и датчиков к указанным пинам.
2. Загрузить [main.ino](main.ino) на Arduino.
3. Поставить машинку рядом с левой стеной/бортиком.
4. При необходимости скорректировать константы дистанции и скоростей под свою механику и покрытие.
