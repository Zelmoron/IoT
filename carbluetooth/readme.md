# Управление двухколесной платформой по Bluetooth

## Введение
Данный проект представляет собой реализацию системы дистанционного управления двухколесной робототехнической платформой с помощью смартфона. Управление осуществляется по протоколу Bluetooth через приложение **Arduino Bluetooth Controller** (в режиме "Controller"). 

Цель проекта — создать надежную связку между аппаратной частью (микроконтроллер Arduino, драйвер двигателей, Bluetooth-модуль) и программной логикой, обеспечивающей плавное и корректное движение платформы во всех направлениях.

---

## Аппаратное обеспечение и схема подключения

Для реализации проекта используются следующие основные компоненты:
1. Микроконтроллер (совместимый с Arduino UNO/Nano).
2. Драйвер моторов (управляемый по логике Направление + ШИМ-скорость).
3. Модуль Bluetooth (HC-05 или HC-06).
4. Двухколесное шасси с моторами постоянного тока.

### Назначение контактов (распиновка)
Драйвер моторов подключается к следующим пинам микроконтроллера:
* **Правый мотор:** 
  * Направление (`DIR_RIGHT`) — Пин 4
  * Скорость ШИМ (`SPEED_RIGHT`) — Пин 5
* **Левый мотор:** 
  * Направление (`DIR_LEFT`) — Пин 7
  * Скорость ШИМ (`SPEED_LEFT`) — Пин 6

**Подключение Bluetooth-модуля:**
* **TX** модуля подключается к **RX** Arduino (Пин 0).
* **RX** модуля подключается к **TX** Arduino (Пин 1).
> **Важно:** При прошивке микроконтроллера контакты 0 и 1 необходимо физически отключать, так как они используются для загрузки кода по USB. В противном случае возникнет ошибка загрузки.

## Программная логика работы

Код написан по принципу модульности, где низкоуровневое управление аппаратной частью отделено от высокоуровневой логики обработки команд.

### Базовая функция движения
Основой управления является функция `move()`. Она принимает четыре параметра: направление и скорость для левого колеса, а также направление и скорость для правого колеса. 
Направление задается логическими уровнями (`HIGH` / `LOW`) через `digitalWrite`, а скорость регулируется с помощью широтно-импульсной модуляции (ШИМ) через `analogWrite` (значения от 0 до 255). В коде установлена базовая константа скорости `BT_SPEED = 200`.

### Обработка команд Bluetooth
В функции `setup()` инициализируется аппаратный последовательный порт (`Serial.begin(9600)`), через который Arduino общается с Bluetooth-модулем.

В основном цикле `loop()` микроконтроллер постоянно проверяет наличие входящих данных:
```cpp
if (Serial.available() > 0) {
    command = Serial.read(); 
    // ... обработка команды через switch-case
}
```

Система реагирует на следующие символьные команды, отправляемые смартфоном:
* **'F' (Forward):** Движение вперед. Оба мотора вращаются в прямом направлении с заданной скоростью.
* **'B' (Backward):** Движение назад. Оба мотора вращаются в обратном направлении.
* **'L' (Left):** Танковый разворот влево (левое колесо крутится назад, правое — вперед). Обеспечивает разворот на месте.
* **'R' (Right):** Танковый разворот вправо (левое колесо крутится вперед, правое — назад).
* **'S' (Stop):** Остановка. На оба мотора подается нулевая скорость.

## Настройка мобильного приложения

Для управления платформой используется приложение **Arduino Bluetooth Controller**. Процесс настройки:
1. Модуль HC-05/06 необходимо сопрячь со смартфоном в настройках Bluetooth (стандартный пин-код `1234` или `0000`).
2. В приложении выбирается подключенный модуль.
3. Выбирается режим **"Controller Mode"** (режим геймпада).
4. В настройках кнопок назначаются соответствующие символы, которые будет отправлять телефон при нажатии:
   * Кнопка "Вверх": `F`
   * Кнопка "Вниз": `B`
   * Кнопка "Влево": `L`
   * Кнопка "Вправо": `R`
   * При отпускании кнопок (или на отдельную кнопку остановки): `S`
